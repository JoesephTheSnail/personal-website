Star project buttons

One small themed object per star project, in the spirit of the truck on the carbon capture page. Palette only: petrol body, graphite tile, bone line art. Hover or tab to a button to see it move, or tick the box.

  • The label stays plain text on the body, so it is still one ordinary link for a screen reader (the art is aria-hidden).
  • Motion plays on hover, keyboard focus and touch press only; it is off under reduced motion. Nothing moves at rest.
  • Pure CSS and inline SVG: about 1.5KB each, no images, no scripts.
  • One per star project (6 stars). The truck on carbon capture stays as the reference; it is the only one allowed off-palette.
